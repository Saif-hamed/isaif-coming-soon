# isaif.om

موقع ثابت (بدون سيرفر) لألعاب وأدوات خفيفة. يعمل على GitHub Pages كما هو.

## الهيكل

```
index.html                  الصفحة الرئيسية (قائمة الألعاب والأدوات)
assets/style.css            الألوان والخطوط والأزرار المشتركة
games/imposter/             لعبة الإمبوستر
  index.html                الصفحة
  app.js                    الواجهة والاتصال بين اللاعبين
  logic.js                  منطق اللعبة (عند المضيف فقط)
  words.js                  قائمة الكلمات، عدّلها بحرية
  imposter.css              تنسيق اللعبة
CNAME                       اسم الدومين لـ GitHub Pages
404.html                    صفحة الخطأ
```

## تشغيل محلي

```
python3 -m http.server 8000
```

ثم افتح http://localhost:8000

## إضافة لعبة أو أداة جديدة

1. أنشئ مجلداً داخل `games/` (أو `tools/`) وضع فيه `index.html`.
2. اربط `../../assets/style.css` لتأخذ نفس الهوية.
3. أضف عنصراً جديداً في قائمة `.index` داخل `index.html` الرئيسي.

## ملاحظات تقنية

- لعبة الإمبوستر تتصل عبر WebRTC باستخدام PeerJS، ويُحمَّل من jsDelivr بنسخة محددة (1.5.4). للاستضافة الذاتية: نزّل الملف إلى `games/imposter/` وغيّر وسم `script` في `index.html`.
- الاتصال الأولي بين اللاعبين يمر عبر خادم PeerJS العام المجاني، وبعدها الرسائل تنتقل مباشرة بين الأجهزة.
- الخط (Tajawal) يُحمَّل من Google Fonts، وإن تعذّر يُستخدم خط النظام.
